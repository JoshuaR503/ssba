# Simulation runs

- **Current target:** Raspberry Pi 5 with 4 GB RAM.
- `pi5-4gb-2026-10-16/`: current single-hardware suite, 360 runs across three controllers,
  four scenarios and 30 workload seeds. All timing and temperature values remain synthetic.
- `both-pi-options-2026-10-12/`: historical exploratory suite from before hardware was
  confirmed. Its original datasets, assumptions and results are retained unchanged for provenance.

The active simulator configuration no longer includes the unneeded hardware alternative.
These datasets are software simulation outputs, not measurements of the physical robot.
